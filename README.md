## 📝 Sobre o Projeto

</div>

Este projeto utiliza a plataforma **Arduino** para monitorar a intensidade luminosa do ambiente de forma automatizada por meio de um sensor **LDR (Resistor Dependente de Luz)** conectado à porta analógica. 

Através da leitura dos valores de luz (`analogRead`), o sistema processa as informações em tempo real e aciona ou desliga um LED de acordo com o limite de limiar configurado no código.
